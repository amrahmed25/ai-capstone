# Week 10 – Send the Link

## How I Will Add My Next Case Study

My next case study will be added to the **Projects/Case Studies section** of my personal portfolio.

I will use the same three-part structure:

### 1. The Problem

I will explain:

* What problem the project solves.
* Who it is designed for.
* Why the project is useful.

### 2. What I Did

I will explain:

* My role in the project.
* The technologies I used.
* The main features I built.
* The important design and development decisions I made.

### 3. What Came From It

I will show:

* The final result.
* Project screenshots.
* The live/demo link.
* The GitHub repository when available.
* Any useful results, feedback, or lessons learned.

### Steps

1. Finish and test the project.
2. Collect screenshots and project assets.
3. Prepare the live/demo and GitHub links.
4. Write the Problem section.
5. Write the What I Did section.
6. Write the What Came From It section.
7. Add the case study to the portfolio.
8. Test it on desktop and mobile.
9. Check all links.
10. Publish the updated portfolio.
