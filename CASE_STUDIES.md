# 1. ElectroHub

### The Problem

Electronics products can be difficult to organize and discover when a store has many categories, components, and technical products. The goal was to build a clean e-commerce experience where users could quickly find products and understand what they are buying.

### What I Did

I built the frontend using React and modern web technologies, focusing on reusable components and a responsive layout. I organized the product experience around clear categories and product information, and worked on authentication and API integration to connect the frontend with the backend.

I also focused on making the interface responsive across desktop and mobile screens instead of designing only for one screen size.

### What Came of It

The result was a complete electronics-store experience with product browsing, authentication, and a responsive interface. The project also gave me practical experience connecting a React frontend to backend APIs and handling real application states.
