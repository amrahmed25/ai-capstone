# Identity Kit

## 1. Typography

**Heading Font:** Inter Bold
**Body Font:** Inter Regular / Medium

I chose Inter because it is clean, modern, highly readable, and works well for a frontend developer portfolio across desktop and mobile screens.

---

## 2. Color Palette

| Purpose          | Color      | Hex       |
| ---------------- | ---------- | --------- |
| Primary / Accent | Teal       | `#14B8A6` |
| Text             | Near Black | `#0F172A` |
| Background       | Near White | `#F8FAFC` |
| Surface          | White      | `#FFFFFF` |

The palette is intentionally limited so the portfolio feels calm and professional while the project screenshots remain the strongest visual element.

---

## 3. Logo / Favicon

### Logo

**AM**

A simple **AM monogram** using Inter Bold. The logo is intentionally minimal so it works well in the navbar, portfolio header, favicon, and social profiles.

### Favicon

The favicon uses the same **AM monogram** to keep the visual identity consistent across the website.

---

## 4. Style Note

**Fonts:** Inter Bold for headings and Inter Regular/Medium for body text.
**Colors:** `#14B8A6` accent, `#0F172A` text, `#F8FAFC` background, and `#FFFFFF` surfaces.

**Mood:** Clean, calm, modern, and technical; the design frames my work without competing with the projects themselves.

---

## 5. Design Principle

The portfolio should feel intentional without being visually overwhelming. I will use the same typography, colors, spacing, and logo throughout the website so every page feels connected.

The projects and their real screenshots should be the loudest part of the portfolio, while the visual identity provides a consistent frame around them.
