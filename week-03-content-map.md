# 5. Content Priority

The portfolio should prioritize proof in this order:

**1. Real projects → 2. Screenshots → 3. Live demos → 4. GitHub/code → 5. Skills → 6. Background**

The strongest project, **ElectroHub**, leads the portfolio because it demonstrates more than a simple landing page and can show both frontend skills and integration with backend functionality.

The overall content map is designed to answer three questions:

**What do I build? → Can I actually build it? → How can we work together?**
