# Week 03 — Curate Your Images

## 1. Final Image Set

### Hero / Landing Section

* **Image:** Hero visual / abstract texture
* **Source:** AI-generated
* **Purpose:** Create a visual introduction that supports the portfolio's modern frontend-developer identity.
* **Style:** Minimal, modern, clean, with the same visual mood as the portfolio color palette.

### About Me

* **Image:** Personal profile photo
* **Source:** Real photo
* **Purpose:** Represent me as the actual person behind the portfolio.
* **Decision:** I chose a real photo instead of an AI-generated portrait because the portfolio should represent the real person and build trust.

### Projects

For each project, I used **real screenshots of my actual work**.

* **Atlas Web** — Real project screenshot
* **Auto Arena** — Real project screenshot
* **ElectroHub** — Real project screenshot
* **Meshwar** — Real project screenshot
* **Blood Link** — Real project screenshot
* **Smart Auto Hub** — Real project screenshot

**Why real captures:**
Real screenshots provide direct proof of my skills and show the actual quality, layout, responsiveness, and implementation of my work. AI-generated replacements could look attractive, but they would not accurately represent what I built.

### Skills / Supporting Visuals

* Minimal icons for technologies such as React, JavaScript, TypeScript, HTML, CSS and Tailwind CSS.
* **Source:** Existing technology icons / simple consistent visual assets.
* **Purpose:** Support the skills section without competing with the actual project screenshots.

---

## 2. Where I Chose Real Images Over AI

I intentionally used real images for:

1. **My profile photo** — because it represents me personally.
2. **Project screenshots** — because they are evidence of my actual work.
3. **UI/project details** — because accuracy is more important than creating a visually impressive fake.

I only used AI-generated visuals for decorative elements where there was no need to represent real work.

---

## 3. AI Image Style

The generated visuals follow one consistent direction:

* Minimal and modern
* Clean digital aesthetic
* Subtle abstract shapes
* Soft gradients
* Limited color palette matching the portfolio
* No unnecessary text
* No realistic people or fake interfaces

The goal was to make the AI-generated images feel like one visual system rather than unrelated images collected from different sources.

---

## 4. Rejected AI Image

### Rejected Option — Abstract 3D Technology Image

I rejected an AI-generated 3D technology image because, although it looked visually impressive, it felt too generic and did not communicate anything specific about my work. It also introduced a different visual style from the rest of the portfolio, which would make the image set feel inconsistent.

I chose a simpler abstract visual instead because it supports the portfolio without distracting from the real project screenshots.

---

## 5. Final Curation Decision

The final image set prioritizes **proof over decoration**.

Real project screenshots are the main visual evidence, while AI-generated images are limited to supporting visuals. The personal section uses a real photo, and the decorative AI visuals follow one consistent style and color direction.

This keeps the portfolio authentic while still giving it a polished and cohesive visual identity.
