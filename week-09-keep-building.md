# The Plan to Keep Building

## How I Will Add My Next Case Study

When I complete a new project, I will add it to my portfolio using the same three-part case study structure:

### 1. The Problem

I will briefly explain what problem the project was designed to solve, who it was built for, and why the project was needed.

### 2. What I Did

I will explain my role, the main technologies I used, the important design and development decisions I made, and how I approached the problem.

### 3. What Came From It

I will show the final result and explain the outcome, including useful metrics, improvements, lessons learned, or user feedback when available.

### Steps to Add a New Case Study

1. Complete and test the project.
2. Collect screenshots and the live/demo link.
3. Write the Problem section.
4. Write the What I Did section.
5. Write the What Came From It section.
6. Add the project to the portfolio projects section.
7. Add the project image and required assets.
8. Test the new case study on desktop and mobile.
9. Check all links.
10. Publish the updated portfolio.
