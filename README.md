# AI Capstone

Capstone project for the **AI-assisted development** track — building a production-ready web application with modern tooling and AI-assisted workflows.

## Status

Early setup — project scaffolding and documentation are in place; application code is coming next.

## About

This repository documents and hosts the development of a full-stack-style web app built with React and TypeScript. The focus is on shipping a polished, maintainable product while using AI tools effectively throughout design, implementation, and iteration.

## Tech Stack

| Layer | Tools |
| --- | --- |
| UI | React, TypeScript, Tailwind CSS |
| Build | Vite |
| Runtime | Node.js |
| Quality | ESLint, Conventional Commits |

## Goals

- Ship a **production-ready** application with a clear scope and solid UX.
- Practice **AI-assisted development** — prompting, review, refactoring, and documentation.
- Keep the codebase **small and maintainable** — functional components, focused modules, consistent style.
